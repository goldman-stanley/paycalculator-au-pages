# PayCalculator AU legal and support site

This static site contains the app's bilingual privacy policy and support contact. It is separate from the iOS source code so the app repository does not need to be public.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `paycalculator-au-pages`.
2. Upload `index.html` to the repository root and commit it to the default branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. Its address will be `https://<your-github-username>.github.io/paycalculator-au-pages/`.
6. Use that address as the App Store Connect privacy policy URL. Use the same address with `#support` as the support URL.

GitHub Pages on GitHub Free requires a public repository. The site is public, and GitHub's privacy statement applies to technical request data recorded when visitors access it. The support address shown on the site is `tmt@goldman-stanley.com`.
